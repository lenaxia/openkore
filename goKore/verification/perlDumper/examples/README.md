# Validation Examples

This directory contains examples of how to use the validation data generated by the Send.pm wrapper.

## Overview

The validation data is generated using the `send_wrapper.pl` script in the parent directory. This script captures the output of Send.pm methods and saves it in JSON format. The examples in this directory show how to use this validation data to test your Go implementation.

## Files

- `main.go`: A simple program that loads and displays validation data
- `example_test.go`: Example tests that compare a mock implementation with validation data

## Running the Examples

### Prerequisites

1. Generate validation data using the `generate_validation_data.sh` script:

```bash
cd ..
chmod +x generate_validation_data.sh
./generate_validation_data.sh
```

This will create a `validation_data` directory with JSON files containing the output of various Send.pm methods.

### Running the Main Example

```bash
cd validation_examples
go run main.go
```

This will display information about the validation data, including the method name, arguments, and packet data.

### Running the Tests

```bash
cd validation_examples
go test -v
```

This will run the example tests that compare a mock implementation with the validation data.

## Creating Your Own Tests

To create your own tests using the validation data:

1. Load the validation data using the `loadValidationData` function
2. Extract the arguments from the validation data
3. Call your implementation with the same arguments
4. Compare the output with the expected output from the validation data

Example:

```go
func TestYourMethod(t *testing.T) {
    // Load validation data
    data, err := loadValidationData("../validation_data/packet_output_yourMethod.json")
    if err != nil {
        t.Skip("Validation data not found")
        return
    }

    // Create your implementation
    impl := &YourImplementation{}

    // Extract arguments from validation data
    arg1, ok1 := data.Args[0].(float64)
    arg2, ok2 := data.Args[1].(string)
    if !ok1 || !ok2 {
        t.Fatalf("Invalid arguments in validation data")
    }

    // Call your implementation with the same arguments
    result := impl.YourMethod(int(arg1), arg2)

    // Convert validation data bytes to a byte slice
    expectedBytes := make([]byte, len(data.Packets[0].Bytes))
    for i, b := range data.Packets[0].Bytes {
        expectedBytes[i] = byte(b)
    }

    // Compare the results
    if !bytes.Equal(result, expectedBytes) {
        t.Errorf("Output doesn't match validation data")
        t.Errorf("Expected: %v", expectedBytes)
        t.Errorf("Got: %v", result)
    }
}
```

## Integration with Your Project

To integrate these examples with your project:

1. Copy the `loadValidationData` function and `PacketData` struct to your code
2. Create tests that load the validation data and compare it with your implementation
3. Run the tests to ensure your implementation matches the original Send.pm behavior

This approach allows you to validate your Go reimplementation against the original Perl code, ensuring compatibility and correctness.
