# Go Utilities for Packet Validation

This directory contains Go utilities for validating packet implementations against the test data generated from the original OpenKore Send.pm module.

## Overview

The `packet_validator` package provides tools for:

1. Loading test data generated by the Perl wrapper scripts
2. Validating Go-generated packets against the expected packets
3. Reporting detailed validation results

## Files

- `packet_validator.go`: The main package with utilities for loading and validating packets
- `example_test.go`: Example tests showing how to use the package

## Usage

### Loading Test Data

```go
// Load a single test data file
moveData, err := packet_validator.LoadPacketData("testdata/sendMove.json")
if err != nil {
    log.Fatalf("Error loading test data: %v", err)
}

// Load all test data files in a directory
allData, err := packet_validator.LoadTestData("testdata")
if err != nil {
    log.Fatalf("Error loading test data: %v", err)
}
```

### Validating Packets

```go
// Create your implementation
impl := &YourImplementation{}

// Extract arguments from test data
x, _ := moveData.Args[0].(float64)
y, _ := moveData.Args[1].(float64)

// Call your implementation with the same arguments
result := impl.SendMove(int(x), int(y))

// Validate the result
validationResult := packet_validator.ValidatePacket("sendMove", moveData.Args, result, moveData)

// Check if the validation passed
if !validationResult.IsValid {
    fmt.Println("Validation failed!")
    for _, err := range validationResult.Errors {
        fmt.Printf("  %s\n", err)
    }
    fmt.Printf("Expected: %s\n", validationResult.ExpectedHex)
    fmt.Printf("Got: %s\n", validationResult.ActualHex)
} else {
    fmt.Println("Validation passed!")
}
```

### Using in Tests

See `example_test.go` for examples of how to use the package in Go tests.

```go
func TestSendMove(t *testing.T) {
    // Load test data
    moveData, err := packet_validator.LoadPacketData("testdata/sendMove.json")
    if err != nil {
        t.Skip("Test data not found")
    }

    // Create your implementation
    impl := &YourImplementation{}

    // Extract arguments
    x, _ := moveData.Args[0].(float64)
    y, _ := moveData.Args[1].(float64)

    // Call your implementation
    result := impl.SendMove(int(x), int(y))

    // Validate
    validationResult := packet_validator.ValidatePacket("sendMove", moveData.Args, result, moveData)
    
    if !validationResult.IsValid {
        t.Errorf("Validation failed: %v", validationResult.Errors)
    }
}
```

## Integration with Your Project

To integrate these utilities with your project:

1. Copy the `packet_validator.go` file to your project
2. Update the import paths as needed
3. Create tests that use the validator to compare your implementation with the test data

## Extending

If you need to add support for additional validation features:

1. Modify the `PacketData` struct to include any additional fields you need
2. Add new validation functions as needed
3. Update the `ValidatePacket` function to perform additional checks

## Troubleshooting

If you encounter errors:

1. Make sure the test data has been generated using the Perl wrapper scripts
2. Check that the paths to the test data files are correct
3. Ensure that your implementation is correctly handling the arguments from the test data
